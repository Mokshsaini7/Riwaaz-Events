# ÉLAN Events — Luxury Wedding & Event Website

Open `index.html` directly in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.

## Edit quickly
- Company name/logo: `index.html`
- Hero/about/services/contact copy: `index.html`
- Gallery images: replace the Unsplash URLs in `index.html`
- Colors/layout: `styles.css`
- Interactions: `script.js`
- Replace the placeholder email, phone and WhatsApp number before publishing.

The site is intentionally built as a lightweight static website with no backend required.
